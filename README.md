# Diksha, Meri Jaan ❤️ — Love Website

## Publish on GitHub Pages
1. Extract the ZIP.
2. Upload `index.html` and the entire `media` folder to the root of your repository.
3. Commit changes to `main`.
4. In Settings → Pages, choose Deploy from a branch → `main` → `/(root)`.
5. Keep the media folder beside index.html. The page uses relative paths such as `media/diksha-1.jpeg`.

This version uses only the three images supplied for Diksha (no videos or stickers). It includes separate page views and a five-question interactive love quiz.
