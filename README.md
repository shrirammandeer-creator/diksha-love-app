# Diksha Love App — GitHub Pages

This version embeds all three original photos directly inside `index.html`. You only need to upload/replace this one file in the root of your `diksha-love-app` repository.

## Publish
1. Open the repository's **Code** tab.
2. Open `index.html` and choose the pencil icon, or use **Add file → Upload files** to upload this replacement.
3. Commit the change to the `main` branch.
4. Wait a few minutes, then hard-refresh the site with Ctrl+F5.

No separate `media` folder is required in this version.
