# Diksha Love App — GitHub Pages

## Files
- `index.html` — complete responsive romantic website (HTML, CSS, JavaScript in one file)
- `media/diksha-1.jpeg`, `media/diksha-2.jpeg`, `media/diksha-3.jpeg` — the three supplied photos

## Publish on GitHub Pages
1. Extract this ZIP on your computer.
2. Open your `diksha-love-app` repository and select the `main` branch.
3. Upload `index.html` to the repository root (same level as README.md).
4. Create/upload the `media` folder with all three JPEG files. GitHub's web uploader can upload multiple files; for a folder, drag the `media` folder or create `media` first and upload its files there.
5. Commit changes to `main`.
6. In Settings → Pages, choose Deploy from a branch, `main`, and `/(root)`.
7. Wait for deployment, then open https://shriramman-deer-creator.github.io/diksha-love-app/ (use your exact GitHub Pages URL shown in Settings).

## Important
The paths are case-sensitive. The folder must be named exactly `media`, and the filenames must match the HTML:
- `media/diksha-1.jpeg`
- `media/diksha-2.jpeg`
- `media/diksha-3.jpeg`

This website includes selected affectionate chat highlights from the chat export. It does not publish the entire private chat.
